# مستخدم إشراق · Esharq User

`user.png` — صورة الشارة. تظهر تلقائياً لكلّ عضو في إشراق، بجانب شارة رتبته إن كانت له رتبة.

`members.json` — معرّفات الأعضاء، تكتبها مهمّة `/api/cron/roster` في الموقع.

**تُوحَّد ولا تنكمش**: من دخل خادم إشراق مرّةً بقيت شارته وإن غادر. هذا مقصود — الشارة
تقول «من إشراق»، لا «في الخادم الآن». الحذف يدويّ من هذا الملفّ.

الملفّ غير موجود قبل أوّل مزامنة، والعميل يتحمّل غيابه: يعود حينئذٍ إلى فحص العضوية من
مخزن ديسكورد المحليّ، فتظهر الشارة لمن يشارك الخادم فقط.
